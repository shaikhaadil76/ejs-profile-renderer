# 📄 EJS Profile Renderer

A simple backend project built using **Node.js**, **Express.js**, and **EJS** that demonstrates dynamic routing and server-side rendering.

The application loads profile data from a JSON file and displays different user profiles dynamically based on the URL parameter.

---

## 🚀 Features

- 📂 Dynamic routing with Express.js
- 🎨 Server-side rendering using EJS
- 📄 Reads user data from a JSON file
- 🖼️ Displays profile images and information
- 📁 Serves static CSS and image files
- 💻 Beginner-friendly backend project

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/ejs-profile-renderer.git
```

Go to the project directory

```bash
cd ejs-profile-renderer
```

Install dependencies

```bash
npm install
```

Run the server

```bash
node index.js
```

Open your browser

```
http://localhost:8080
```
